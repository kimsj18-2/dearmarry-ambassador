# DEAR MARRY Ambassador Invitation

React + Vite + CSS 3D로 구현한 한 화면형 엠버서더 초대장입니다.

## 현재 구현 범위

- 화면 중앙의 소개장 봉투 한 장
- `You’re Invited` 금박 필기체
- `AMBASSADOR · No. —` 넘버링
- 업로드 이미지에서 애니메이션 봉투로 전환
- 실링 해제 및 봉투 덮개 개봉
- 편지지 추출과 좌우 CSS 3D 펼침
- 모바일 세로형 초대장 전환
- 초대장 다시 접기
- 모바일 축소 대응 및 모션 최소화 설정 대응

## 실행

```bash
npm install
npm run dev
```

배포 파일은 아래 명령으로 `dist`에 생성합니다.

```bash
npm run build
```
